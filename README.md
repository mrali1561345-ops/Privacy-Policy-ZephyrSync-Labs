# Privacy Policy for ZephyrSync Labs

Last updated: November 2026

**ZephyrSync Labs** is built as an offline utility application. This service is provided at no cost and is intended for use as is.

### Data Collection and Usage
ZephyrSync Labs does **NOT** collect, store, transmit, or share any personal or non-personal user data. 

* **Offline Functionality:** All calculations (including age metrics and budget splits) are processed locally on the user's device.
* **Third-Party Services:** The app does not integrate with any third-party SDKs, analytics frameworks, advertising networks, or external cloud servers.
* **Device Permissions:** The application operates without requesting sensitive device permissions or network access.

### Children's Privacy
Because the application does not collect any data, it is safe for all age groups and fully compliant with global privacy standards.

If our privacy practices change in the future, this policy page will be updated accordingly.
